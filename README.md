# CLOUD Store Bot 🤖

Telegram бот для продажи архивов за Telegram Stars и криптовалюту.

## Функции

- 📦 Каталог пакетов (5, 10, 20 ГБ)
- ⭐ Оплата через Telegram Stars
- 💎 Оплата криптовалютой (USDT TON, USDT TRC20, GRAM)
- 💳 Оплата картой (через менеджера @oplataoi)
- 🆘 Техподдержка с тикетами
- 🛒 История покупок

## Установка

1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти: `python bot.py`

## Прайс-лист
